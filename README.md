# Pure Python Fundamentals 🐍

Welcome! This repository is a collection of programs and algorithms built entirely in **Vanilla Python**, without importing a single external library (no `math`, no `numpy`, nothing!). 

The goal of this project is to showcase a deep, granular understanding of Python's core fundamentals, data structures, and logic by building analytical tools from scratch.

## 🚀 Featured Project: From-Scratch Mean Calculator

Instead of just running a library function, this program manually processes inputs to calculate statistical means, proving a solid grasp of:
* Core arithmetic logic handling
* Clean loops and data aggregation
* Robust error handling for edge cases (like empty inputs)

### 🛠️ How it Works (Under the Hood)
Without relying on built-in helper functions for complex math, the logic relies purely on primitive types and control flows to compute results accurately. 

## 📂 Other Contents
This repo also serves as a timeline of my coding journey—tracking basic programs, playground scripts, and academic challenges where I break down problems into raw Python logic.

## 🧠 Why Build Without Libraries?
Libraries are great for production, but writing code from scratch forces you to understand *the algorithm* rather than just *the syntax*. It proves I don't just know how to use Python—I know how Python works.
